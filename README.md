# Fleet & Air Names · 海空军动态命名

Victoria 3 1.15.x 脚本版。包含简体中文和英文。

## 安装和使用

1. 将本仓库目录放入 Victoria 3 用户数据目录下的 `mod/`，保留目录内的 `.metadata/`，在启动器中加入播放集。
2. 在日志的「决议」中点击「查看舰队命名」。首次使用会登记本国舰队，之后每月自动补登记。重复点击按编号轮转，查看最新的建议名。
3. 在原版舰队改名框输入建议名。可将自定义命名的舰队锁定，使其退出建议队列。解锁决议将本国锁定舰队一起恢复到队列。
4. 1903 年起可登记航空中队。查看决议轮转已登记的编号，按当前首都显示行政驻地。

舰队建议优先考虑独占历史称号，再考虑国别、政体和常驻 HQ。大舰队、联合舰队与北洋舰队的实现规则只允许编号 1 获得相应称号，且仍须符合国家、年代及其他门槛。编号不回收。首个编号消失后称号也停止出现。舰队转属后由新所属国分配编号，锁定状态随存续编制保留。

当前任务海域支持原版脚本文档示例中的孟加拉湾补给护航。其他任务保留基础名，国别战争状态单独显示。建议在打开事件时依据当前状况解析，原版舰队名称、单舰、司令和作战状态由原版管理。

航空名册用日期门槛、连续编号及当前首都表示行政编组。每个编号可在名册重访，编组没有单独驻地或作战属性。现有原版名称和其他 Mod 的自定义名称由玩家在采用前核对。

# Fleet & Air Names · 海空军动态命名

面向 Victoria 3 1.15.x，包含简体中文和英文。

## 安装和使用

1. 退出游戏。更新时先把旧 Mod 目录移出 `mod/`，再放入完整的新目录，保留 `.metadata/`。在启动器里只启用一个副本。
2. 在日志的「决议」里选择「查看舰队命名」或「查看陆军命名」，每次查看一支编队。可在原版改名框输入建议名。
3. 1903 年起可登记航空中队，重复使用查看决议可翻阅航空名册。

舰队建议参考国家、政体、年代与常驻 HQ。陆军平时优先使用占至少六成的征募州，其次使用常驻 HQ。动员时可显示当前前线或指挥官前线。编成、主要型号、运输与物资配置在查看时计算。全国补给网络和已分配补给舰数分别显示。

## 0.2.2 启动兼容性修订

陆军和舰队通过国家级游标轮阅。建议名中的数字是当前列表位置，编队新增、解散或重新排序时可能变化。历史专名仍有时代和条件门槛，首位编队可获得对应建议。此版本撤下陆海军的持久编号、锁定、月度登记和编成防抖。已有存档中手动采用的名称继续由游戏保存。

首轮复测请在启动器用只启用本 Mod 的播放集点击「开始游戏」，进入主菜单后再测试新局。若可进入主菜单，再单独尝试旧存档。若仍闪退，记录游戏版本、崩溃发生阶段及最新的 `logs/error.log` 和崩溃目录中的 `exception.txt`。当前环境未运行游戏客户端。

## 编队自定义按钮测试分支

这个分支验证 1.15 原版编辑框的文本绑定能否把固定测试名交给原版「确认」。界面补丁从本机游戏安装生成。

1. 退出游戏，将本分支放入 Mod 目录，并在启动器中只启用这一份。
2. 在本分支目录运行 `python3 tools/install_rename_probe.py "/实际安装路径/Victoria 3/game"`。参数应当是包含 `gui/` 的游戏目录。脚本会打印生成的文件路径。
3. 开启测试存档，任选一支陆军或舰队，记下原名。打开「编队自定义」，点「测试生成名称」，观察输入框是否显示 `DFN Rename Probe`。
4. 保持输入框原样并点击原版「确认」。返回编队面板，查看实际名称。**只有面板里的真实名称变成测试名，才算通过。** 再对另一军种测试一次，并验证普通手动改名。
5. 如未通过，请记录按钮是否出现、输入框是否变化、确认后的实际名称，以及 `error.log` 中最早的相关报错。测试按钮的预填状态限于客户端会话，按编队区分，第二次点击同一按钮可关闭。

撤销测试时先退出游戏，再移除本分支目录下安装脚本打印的文件，或切回之前的 Mod 副本。
